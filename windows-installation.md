# 🖥️ Windows 11 Installation Guide

A step-by-step guide to installing Windows 11 on a compatible system.

---

## ✅ Prerequisites

- Windows 11 ISO file
- USB drive (≥ 8GB)
- Internet access

---

## 🚀 Steps

### 1. Create Bootable USB  
Use Rufus or similar tools.

### 2. Boot from USB  
Access BIOS and select USB boot option.

### 3. Install Windows  
Follow setup wizard prompts.

---

## 📎 Notes  
- Backup your data  
- Check system compatibility  
- Keep drivers ready
